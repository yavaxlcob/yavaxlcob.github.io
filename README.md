## Управление и доступность

- Комплектация: пять вкладок, стрелки влево/вправо, Home и End.
- Галерея: шесть фотографий; стрелки, Escape, возврат фокуса и свайп.
- Анимация учитывает `prefers-reduced-motion`, изменение системной настройки и отдельную кнопку остановки в подвале.
- Canvas-анимации рисуются только у видимых секций; в скрытой вкладке отрисовка приостанавливается.
- Активные внешние ссылки на странице ведут только в Telegram: `https://t.me/yavaxlcob`.

Временные инструменты и исходники проверки находятся в исключённой из Git папке `.qa/`.

## Проверка этой локальной итерации

Проверено в браузере при фактической ширине 1920, 1440, 768, 390 и 360 CSS px.
Горизонтального переполнения не выявлено. Четыре указанных в ТЗ крупных заголовка на desktop занимают по две строки. Минимальный функциональный шрифт — 14 px, основной текст — 18–22 px.

Проверены пять вкладок и клавиши Home/стрелки, четыре состояния истории, восемь цветов, открытие/листание/закрытие галереи и возврат фокуса, мобильное меню, FAQ, отсутствие пересечения тем клуба и CTA. Проверены локальные ресурсы, якоря, Telegram-ссылки, canonical, Open Graph и четыре вопроса в FAQ JSON-LD.

Кнопка остановки анимации проверена в браузере: анимации отключаются, переходы имеют длительность 0s. Системная ветка `prefers-reduced-motion` и обработчик её изменения проверены в коде; отдельная эмуляция системного media preference в этой проверке не выполнялась.

Это локальная дизайнерская итерация для дальнейшего совместного просмотра, не утверждённый финальный дизайн. Новые изменения не отправлены в GitHub.
