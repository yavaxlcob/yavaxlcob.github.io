# YAVA XL COB — клуб владельцев

## Последняя локальная правка — блок выбора стиля

Белый цвет выбран по умолчанию. Блок стал компактным: на desktop заголовок и примечание однострочные; при 1280 × 720 его высота около 704 px. На телефоне 390 × 844 высота около 747 px, примечание переносится для читаемости.

Вода из существующего `reservoir-water.webp` заполняет всю секцию, без неба и прямоугольной вставки; края мягко переходят в соседние разделы. Canvas плавно деформирует фотографическую водную поверхность, лодка покачивается по тому же времени анимации. Отрисовка учитывает видимость секции и настройку reduced-motion.

В этом блоке восемь пятнистых цветных фотослоёв заменены ровными CSS-заливками с мягким световым переходом. Исходная альфа-маска борта сохранена; кабина, мотор и остекление остаются оригинальной фотографией. Это условная цветовая визуализация, не точная передача заводской краски. Исходные файлы производителя не изменены. Все восемь цветов просмотрены, белый по умолчанию, отсутствие переполнения и остановка анимации проверены. Изменения только локальные, без GitHub.

Статический сайт: HTML, CSS, JavaScript. Без сборки и серверных зависимостей.

## Управление и доступность

- Комплектация: пять вкладок, стрелки влево/вправо, Home и End.
- Галерея: шесть фотографий; стрелки, Escape, возврат фокуса и свайп.
- Анимация учитывает `prefers-reduced-motion`, изменение системной настройки и отдельную кнопку остановки в подвале.
- Canvas-анимации рисуются только у видимых секций; в скрытой вкладке отрисовка приостанавливается.
- Активные внешние ссылки на странице ведут только в Telegram: `https://t.me/yavaxlcob`.

Временные инструменты и исходники проверки находятся в исключённой из Git папке `.qa/`.
